# Aletheia Bible Fellowship

Modern, mobile-first website and installable PWA for ABF PDX.

## Local development

```sh
npm install
npm run dev
```

## Production

`npm run build` generates the deployable site in `dist/`. Pushes to `main` deploy automatically through GitHub Pages. Before changing DNS, configure `abfpdx.org` as the custom domain in the repository's Pages settings and review the deployed preview.
